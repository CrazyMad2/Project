# UrbanEscape

UrbanEscape is a Kotlin + Jetpack Compose Android app targeting Google Play. This repo bootstraps the first playable flow with mocked data and a smart start flow using DataStore.

## Requirements
- Android Studio Hedgehog+ / Koala
- JDK 17
- Android SDK 34

## Run (build + tests)
```bash
cd android
./gradlew :app:test :app:assembleDebug
